# mario-air-racing

正式遊戲由 [myauras 的 GitHub Pages](https://myauras.github.io/demo-game-client/mario-air-racing/) 提供。`master` 保存本專案原始碼，`gh-pages` 分支的 `mario-air-racing/` 放置 `dist/` 內的檔案。

用支援 WebGL 的瀏覽器開啟 [dist/index.html](dist/index.html) 即可遊玩。

若要使用本機預覽網址，在本目錄執行下列指令，再開啟 [本機遊戲](http://127.0.0.1:4186/)。

```powershell
python -m http.server 4186 --bind 127.0.0.1 --directory dist
```

遊戲點數與當局進度儲存在瀏覽器。固定使用同一個瀏覽器和網址即可沿用進度。

## 倍率與結算

倒數 7 秒後起飛。飛行、障礙物和場景隨時間持續加速。一般賽段約 16.1 秒，任一架在飛行中達 1.50× 即延長至約 22.8 秒，上述時間另加衝線演出。每條賽道的風勢決定危險物的密度和強度。2,048 條賽道中有 1,262 條會全數墜機，最後一架墜落即收尾。飛機從 0.10× 起步，每 20 個模擬步累積 0.01×，金幣另外累加，基礎倍率上限為 100×。吃到金幣時，接觸點會爆出金色星芒，拾取的飛機會拉出金色尾流並短暫向前加速。

大型海鳥或隕石直接擊中機體會造成墜機。亂流中，兩架景深相近的飛機高速靠近並撞上時，也會一起墜落。火花與爆炸在接觸點出現。自己下注的飛機碰撞時，賽道短暫閃光並輕震。墜機時震動加重，賽道稍微轉灰，下一局恢復原色。

金色皇冠標記當下飛在最前面的飛機。賽段結束時，存活飛機按前後位置進入衝線直道，每架通過氣球吊起的方格彩帶時噴出彩紙。鏡頭先跟拍冠軍，再依序特寫後續完賽者。若全數墜機，最後墜機者奪冠，同時墜機則取較靠前者，位置也相同時由固定機位決定。冠軍以「下注點數 × 基礎倍率 × 2」結算，其他飛機按自己的基礎倍率結算。

後機會對準前機的高度與景深，從機尾追撞。前機會落後一段距離，將 0.10× 轉給後機。前機有足夠的額外倍率且後機有收取空間時才會觸發。接觸點會迸出閃光，後機的倍率以金字上跳，前機的倍率以紅字下沉。追撞、道具和派彩由已抽出的賽道按固定模擬步重播，加速曲線決定每秒推進的步數，鏡頭、畫面更新率與亂流線只影響顯示。

每台飛機有 2,048 條等機率賽道，每條賽道有五種等機率機位輪替。計入冠軍雙倍後，每台的 10,240 種結果合計派彩 9,728 倍單注，理論 RTP 各為 95%。更新前已開的局沿用該局儲存的規則版本。
