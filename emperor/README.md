# 皇帝牌｜HTML Demo

遊戲 E 的純本地 Demo（暫名「皇帝牌」，外皮候補「王與叛徒」）。**唯一規格依據：`reports/E規格書_v1.html`（v1，含 §Q 裁決紀錄與 E03-R4／E04-R3／R4 勘誤）**；鐵表與歷次變更：`TASKS-E.md`。

一句話說明：選邊（皇帝側 p=0.8／奴隸側 p=0.2）下注，五回合對局決勝負，贏了可續戰爬階梯、隨時收手入袋；越過滿貫線 120x 或十階完賭由系統代收並享頂端加成。兩檔 RTP——提早收手 0.93、玩到頂 0.96。

## 運行方式

零依賴、零建置、無 ES Modules、無 Web Worker、無 fetch。普通 `<script>` 串接即可。

- 雙擊 `index.html`（`file://` 直開）即可遊玩，資料存在瀏覽器 localStorage。
- 也可用任意靜態伺服器（`npx serve` 之類）開啟；線上版見 GitHub Pages 的 `emperor/` 子路徑。
- 數值自測：`node test/mc-test.js 1000000`（Node，無需套件；37 項蒙地卡羅與單元檢查，約 2 分鐘）。

三個頁面：

| 頁面 | 用途 |
|---|---|
| `index.html` | 遊戲主頁（普通／進階雙機位、階梯、滿貫演出、自動下注、勝負紀錄） |
| `sim.html` | 數值驗證頁（E01：靜態推導表＋瀏覽器端蒙地卡羅） |
| `dev.html` | 核心抽查頁（E02：不含美術的狀態機操作面板） |

### 網址參數

| 參數 | 作用 |
|---|---|
| `?dev=1` | 顯示導演台（劇本強制本階勝／敗、重置錢包）。**預設網址不帶此參數，正式遊玩看不到導演台。** |
| `?fx=1` | （已無作用）Demo 演出一律全開，不讀系統 reduced-motion；保留只為舊連結相容 |
| `?rm=1` | 強制走 reduced-motion 降級路徑（直接落牌、不切半） |
| `?shot=…` | 截圖自動駕駛：`slam`／`ladder3`／`full`／`full9`／`adv-flip`／`adv-wait`／`adv-shock`／`adv-slam`／`auto-run`／`auto-modal`／`log-list`／`log-detail`／`log-full` |
| `?vw=375` | 鎖 app 寬度並靠左（headless 截圖裁圖輔助） |

導演台是開發參數，只改「本階勝負」那一次隨機抽樣（包一層 rng），不動核心程式、不影響賠率與 RTP。

## 檔案分界（轉引擎時的所有權約定）

本 HTML 版定位為**原型**，正式版可能轉 Cocos / Unity。下表的「可移植」層是邏輯資產，「拋棄式」層是畫面。

| 檔案 | 定位 | 所屬任務 | 轉引擎時 |
|---|---|---|---|
| `values.js` | **可移植・凍結**：數值單點反推（CFG 五常數→賠率、收手值 M、頂端加成、滿貫判定、上界），全表由程式導出、禁手改單點 | E01 | 邏輯照搬（常數與公式即規格） |
| `js/duel-core.js` | **可移植・凍結**：零 DOM 對局核心——狀態機（BET／PLAY／ANIM／LADDER）、勝負抽定、普通腳本編排、進階反應式對手（含 N1 修正）、階梯與觸頂自動結算、Q2／Q3 逾時、取整與顯示格式、localStorage 重整接回 | E02（E03-R4 修兩行：錯開局牌數自洽） | 邏輯照搬；rng 與持久化換成後台 |
| `sim.js` | 半可移植：數值驗證與蒙地卡羅（瀏覽器端） | E01 | 上線前驗算用，不進產品 |
| `test/mc-test.js` | 半可移植：Node 無頭蒙地卡羅＋單元回歸（37 項） | E02 | 改寫為 CI 腳本 |
| `js/game-ui.js` | 拋棄式：普通模式（觀賽機位）版面與演出編排、三態面板、橫式對數階梯條、滿貫三段揭示、導演台、重整接回；並輸出共用 API `window.EUI` | E03／E05 | 畫面重做（節拍與編排公式可參考） |
| `js/ui-advanced.js` | 拋棄式：進階模式（第一人稱）——CSS 3D 透視牌桌、扇形手牌、立繪六幀差分＋台詞泡泡、Q3 倒數與逾時代出、右緣直式階梯條 | E04 | 畫面重做；台詞／表情池可沿用 |
| `js/ui-atmos.js` | 拋棄式：氛圍層——自動下注三件套（⟳ 鈕／底部設定彈窗／專屬槽浮條）、勝負 log 頁（總覽→詳細、拖曳滾動、錢包重置）、連勝標籤 | E06 | 畫面重做；資料接後台 |
| `css/game.css` | 拋棄式：普通機位版面與演出（拋物線出牌、斬牌、滿貫幕層） | E03／E05 | 重做 |
| `css/advanced.css` | 拋棄式：進階機位 3D 舞台、立繪、扇形手牌 | E04 | 重做 |
| `css/atmos.css` | 拋棄式：自動下注槽、log 頁、彈窗、toast、z 序定義 | E06 | 重做 |
| `index.html` | 拋棄式：骨架與掛點 | E03 起累加 | 重做 |

**script 載入順序固定**：`values.js → js/duel-core.js → js/ui-advanced.js → js/game-ui.js → js/ui-atmos.js`。`ui-advanced` 必須早於 `game-ui`（它要在 `createGame` 之前覆寫進階模式的出牌秒數 `DuelCore.TIMING.PLAY_MS`＝12s，並註冊 `window.EAdv` 供 `game-ui` 初始化）；`ui-atmos` 最後載入（依賴 `window.EUI`）。

## 數值與紀律（改東西前先讀）

- **禁手改單點**：所有倍率、收手值、加成、滿貫判定都由 `values.js` 的五個常數推導。要調 RTP 只准動賠率表與牌組級距，**嚴禁暗改勝率 p**。
- 兩檔 RTP：提早收手 0.93／玩到頂 0.96；滿貫線 120x；十階完賭；頂端加成 ×1.0323。
- 基礎賠率：奴隸側 4.65x、皇帝側 1.1625x。最大實付實例：純奴隸第 4 階收手值 581.25x → 實付 600.00x（500 注＝300,000）。
- 顯示值 2 位無條件捨去（§Q1），結算走全精度，實付恆 ≥ 顯示值。
- 1/5 定理：特殊牌在五張中的位置不影響勝率，因此**玩家出牌順序不影響機率**；表情與台詞是演出，不含機率資訊。
- 效能紅線：所有 transition／animation 只動 `transform`／`opacity`，陰影靜態不參與動畫，禁 `filter`（目標裝置為舊手機）。
