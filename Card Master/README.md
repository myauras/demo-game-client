# 卡牌大師 · Card Master H5 demo

直接以瀏覽器開啟 `index.html` 即可遊玩，無建置或安裝需求。手機與桌面皆可使用。Google Fonts 無法連線時自動使用系統字型。

也可在此資料夾以 `python -m http.server 4173 --bind 127.0.0.1` 啟動，瀏覽 `http://127.0.0.1:4173`。

## 規格來源

[小遊戲草案文件／卡牌大師](https://docs.google.com/spreadsheets/d/1xUDoHdrmYn3xl0gpig5PwZveQumyH6IyaVh-klKL-KA/edit?gid=1390869444#gid=1390869444)，讀取日期 2026-09-11。

實作：完整 52 種撲克牌、選擇翻開 5～36 張、完全相同花色與點數重複即失敗、全數不重複即獲勝。採原創深色金邊奇幻卡牌介面，未使用其他遊戲資料夾或第三方遊戲美術。

## Demo 假設與操作

- 抽牌為「放回抽樣」，每次均由 52 種牌獨立等機率抽取；否則不會出現原企劃要求的重複牌。
- 原始文件沒有正式倍率表。成功機率為 `∏(52-i)/52, i=0…n-1`，示範倍率為 `floor(0.96 / 機率 × 100)/100`。這是 demo 設定，不代表正式營運數值。
- 開局扣除投入點數，成功回報包含本金；獎勵以小數第 2 位結算。
- 初始 10,000 模擬點數；右上角「＋」可重設點數並清空紀錄。無金流、帳戶、伺服器或真實獎品。
- 牌局中鎖定張數、投入點數與重設按鈕；可切換快速翻牌。
- 本機儲存模擬點數；若瀏覽器禁止儲存，當次仍可操作。重新載入會中斷進行中的牌局，已扣除的投入不退回。多分頁沒有共享狀態鎖，請以單一分頁體驗。
- 亂數使用 `Math.random()`，供互動原型使用。

## 檔案

## 直式 UI（依使用者附圖調整）

- 右上餘額、上方倍率、中央 4 欄 × 13 列牌陣，花色依序為梅花、黑桃、方塊、紅心，點數由 A 至 K。
- 底部兩列操作：下注金額與減半／加倍、10／50／100／200 快捷金額、5～36 張下拉選單、投注按鈕。
- LOL／海克斯科技風格的深藍面板、古金鑲邊與青綠光效，使用 CSS 繪製原創介面。
- 桌面維持置中的直式遊戲框；較矮的視窗可垂直捲動。

## 圖片資產

- 遊戲背景使用 `assets/background.webp`，由使用者提供的 965×1630 PNG 縮為 720×1216 WebP（品質 82），容量由約 1.96 MB 降至約 89 KB。
- 倍率面板使用 `assets/multiplier-panel.webp`，由使用者提供的 661×175 透明 PNG 縮為 480×127 無損 WebP，容量由約 122 KB 降至約 45 KB。
- 四花色卡牌底板使用 `assets/suit-panels.webp`，由使用者提供的 395×434 透明 PNG 縮為 360×396 WebP，容量由約 186 KB 降至約 16 KB；52 個花色與點數直接排列於對應面板內。
- 後續替換圖皆先依遊戲實際顯示尺寸縮放，再轉成適合瀏覽器的壓縮格式；專案不直接引用原始大圖。

## 程式檔案

- `index.html`：頁面與規則
- `style.css`：響應式視覺與翻牌動畫
- `game.js`：機率、倍率、抽牌及結算
- `app.js`：互動流程、歷史與本機儲存
- `game.test.cjs`：核心規則驗證，以 `node game.test.cjs` 執行
