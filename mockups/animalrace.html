路子總覽與心情疊加

下注階段的預設畫面、點珠詳情彈窗，以及把增減量直接畫在屬性條上的心情疊加規格。

2026-09-01 ／ 動物大賽跑（機制同樣適用無人機版）／ 放大版，僅此兩主題

Part 1 ── 路子總覽（下注階段的預設畫面）

下注 15 秒期間，演出區顯示此總覽。預設頁籤是「珠盤路」（所有紀錄）；讀法：一局一珠、由上往下填，滿六珠換下一列（與百家樂珠盤相同）。

「出包路」頁籤——把每局壓成二元（有出包／零出包）後，就是標準百家樂路：同結果往下疊、結果改變換新列。大眼仔／小路／蟑螂路演算法原封不動。

Part 2 ── 點珠詳情（彈窗）

點珠盤任一珠彈出該局完整紀錄——總覽答「趨勢」，詳情答「這局到底發生什麼」。

Part 3 ── 心情疊加條（增減量直接畫在屬性條上）

依您的方向修改：不再只給圖示——加成疊在原條後面（亮色延伸段）、下降蓋在原條上（斜紋損失段），增減幅一眼可見，並與賠率變動（▲▼）對應。

押路（大小／奇偶／冷熱）與自動下注

「特殊」頁籤四列面板，以及自動下注三件套（入口鈕、設定彈窗、進行中浮條）。

互動規格（沿用既有手勢語言）

  • 手勢點大按鈕＝以當前籌碼成注（沿用原零出包面板手勢），✓ 脈衝＋藥丸飛入注單列照舊；動物卡轉純資訊（同原零出包模式）。原「零出包」獨立頁籤與主打面板移除。
  • 賠率公式定價（裁決 1-a）：機率直接取 roads.js 既有的 2⁸ 解析勝率加總（大＝5–8 號勝率和、熱門＝前三熱門勝率和…），賠率＝0.95／機率 向下取兩位——零 MC、跨裝置決定性天生成立；每局隨屬性/心情自然浮動。正式版再做 MC 複驗與防套利精算。
  • 結算只看「冠軍編號屬於哪組」＋零出包沿用——轉接層純函數即可判（B05 先例：settle 本就在 adapter 實作），mock-server-b 維持凍結不動。
  • 連動路子區正在看「大小」頁籤時切到特殊，對應那組微微發光提示（看哪路押哪路）。
  • 結算頁log 詳細頁注單直接多注別名，其餘沿用。
工程代價（v2 重估）：公式定價＋轉接層結算＋面板 UI，不解凍任何檔案，估 半天。備選 1-b（按鈕半透明純展示、標「正式版開放」）約 1 小時，但既然公式版這麼便宜，建議直上可玩版。RTP 未經 MC 複驗一事在規格 §12 記一筆，正式版補驗。

二、自動下注（續押）

觀賽型遊戲的掛機需求：設好一次，接下來 N 局自動照押，人只看戲。純 UI 層實作——每局開盤時把「範本注單」自動送引擎，不碰任何凍結檔。

回答您的問題（popup 還是擺在 UI 中）：示意採兩態混合——「設定」是點 ⟳ 鈕才彈出的底部彈窗（下注區已經很密，四個欄位常駐會擠壓動物卡；手機慣例也是 bottom sheet），設完即收；「進行中」則是常駐嵌在 UI 裡的橘色浮條（進度／損益／停止鈕直接可見，不用再開窗）。若您偏好全程不彈窗，備案＝設定欄位收進注單列展開區，代價是選注空間變小——預設建議照示意做。

行為規則

  • 範本以「本局已確認的注單」為範本逐局重押（注別＋金額原樣）；賠率照每局新盤浮動。
  • 停止四種停法：跑滿局數／觸及停利／觸及停損／手動點停止。餘額不足當局自動終止＋跑馬燈提示。
  • 狀態進行中頂部常駐橘色浮條（第 n/N 局＋累計損益＋停止鈕）；每局結算照常走派彩動畫與 log 記錄，order id 照發。
  • 邊界手動加注會併入當局但不改範本；重整頁面自動狀態由 localStorage 接回（同局重整不重複下單）。
工程代價：純拋棄層（game.js＋小面板），凍結檔零接觸，估 半天。風險低，展示「掛機觀賽」的產品感很划算。
