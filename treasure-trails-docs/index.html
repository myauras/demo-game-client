三路尋寶 玩法介紹

HTML Demo｜2026-11-24

三條路選一條出發，冒險者一路收寶物、擲骰子打敵人。打輸扣一顆心、原地再打一次；心扣完就帶著已經收到的寶物撤退。一局只要按一下「出發」，十幾秒結束。

Demo 連結

Demo 連結：https://myauras.github.io/demo-game-client/treasure-trails/

用手機直式開啟最接近實際樣子；電腦瀏覽器也能玩。不用登入，進去直接按「出發」。

怎麼玩

  1. 用上方分頁選一條路：穩、中、拚。分頁上的心就是這條路有幾條命（3、2、1 顆）。命越少越難走到底，但路上的寶物越大。
  2. 選注額：100、500 或 1,000。
  3. 按「出發」。之後不用再做任何事，看冒險者自己走完。

右上角的雙箭頭可以切換速度：預設是普通速度，按一下變成高速。演出中點畫面任何地方也可以加速。

規則

  • 地圖每局都換：節點數、敵人的門檻、寶物大小、路的走向都不一樣。出發前地圖是攤開的，整條路上有什麼都看得到。
  • 寶物：走到就收下。上面的數字是倍率，拿回＝倍率×注額。金幣不到 1 倍、寶石 1 倍以上、大寶藏 10 倍以上。最大的一顆永遠在路的盡頭。
  • 敵人：身上標著「8+」這樣的門檻。擲兩顆骰子，點數加起來達到門檻就贏，繼續往前。門檻顏色綠色好打、黃色普通、紅色難打。
  • 打輸：扣一顆心，留在原地對同一隻再擲一次。
  • 撤退：心扣完就回頭，已經收下的寶物照拿。
  • 拿回＝這一局收下的所有寶物加起來。
  • 三條路長期的拿回比例相同（約 96.5%），差別在「多常拿到」和「拿到時多大」。

一局的流程

地圖下方是「戰利品」：每收一顆寶物多一格，最右邊是這一局累計拿回多少。

其他功能

  • 自動下注：「自動」鈕可以設定局數、停利、停損，自動連玩。
  • 紀錄：右上角可以看最近 50 局，點進去能看這一局收了哪些寶物、每一次擲出幾點。

關於這個 Demo

這是用來驗證玩法的原型，下面這些不是正式的：

  • 沒有伺服器：結果在您的瀏覽器裡算出來，餘額也只存在這台裝置的瀏覽器裡，清除瀏覽資料就歸零。
  • 錢是假的：起始 10,000，玩完了可以在紀錄頁按「重置錢包」。
  • 美術是暫代：冒險者、敵人、寶物、地圖都是程式畫的佔位。
  • 沒有音效，也沒有新手引導。
  • 「回報」鈕只會跳提示，不會真的送出。
  • 三條路的手感差很多：「穩」幾乎每局都拿得到一點，大約每三局有一局不虧，但最大的寶物多半只有 2 倍；「拚」只有一條命，四成的局什麼都拿不到，偶爾一局拿回幾十倍。這是刻意的設計。
  • 數值是 Demo 用的，正式版會再調整。
