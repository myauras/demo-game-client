# 雷射潛入｜H5 Demo

手機直式科幻潛入遊戲 Demo。玩家從盤面最上排選擇起點，以滑鼠或觸控拖曳上下左右相鄰圓格，最後停在最下排後確認潛入。遊戲包含三種難度、逐格獎勵／警戒事件、角色移動、虛擬下注、可恢復的單次結算與逐路線長度 RTP 95% 模型。

## 啟動

此專案沒有第三方依賴，只需要 Node.js 18 以上版本：

```powershell
node server.mjs
```

瀏覽器開啟 `http://127.0.0.1:4173`。也可以直接用任何靜態 HTTP 伺服器提供此資料夾；請勿用 `file://` 開啟，因為瀏覽器會阻擋 ES modules。

## 操作方式

1. 選擇「普通 3×3」、「中等 4×4」或「困難 5×5」。
2. 從最上排任一圓格開始，拖曳或逐格點擊相鄰圓格。不可斜走或重複經過同一格；回到上一格會撤銷最後一段。
3. 路線尾端停在最下排、下注有效時，點「投注」。玩家即使已到達底排也可繼續繞路，但最後一格仍須回到底排。
4. 起點不抽事件，其餘每個有效圓格只會出現金幣、金幣堆、金條堆、鑽石或警戒觸發。警戒立即失敗；成功抵達終點則支付 `下注 × 累積倍率`。
5. 右上角餘額旁的「＋」每次可增加 1,000 點 Demo 虛擬餘額。

若路線連接盤面全部圓格且最後停在最下排，倍率面板會預告「全盤 ×2」。只有成功走完全盤後才會將累積倍率乘以 2；途中警戒時加倍失效且獎勵歸零。每局最多套用一次。

虛擬餘額、未完成行動及最近結算保存在 `localStorage`。重新整理若發現已扣款但未結算的行動，會以原 seed 與已產生的事件繼續，不會再次扣款或重複支付。

## RTP 公式

令路線總格數為 `L`、事件格數為 `n = L - 1`、四種獎勵的條件平均倍率為 `M`，全盤獎勵係數為 `B`（一般路線 `B = 1`，全盤路線 `B = 2`）。每個未觸發警戒的事件格必定產生一種獎勵；依實際路線長度反推單格通過率 `r` 與警戒率 `p`：

```text
r = (0.95 / (n × M × B)) ^ (1 / n)
p = 1 - r
S = r ^ n
RTP = S × n × M × B = 0.95
```

程式啟動時會枚舉 3×3、4×4、5×5 盤面的所有可達路線長度，並將全盤 ×2 納入各難度最長路線的機率反推，確認每個 `p` 都在 `[0, 1]` 且理論 RTP 仍為 95%。若任何組合無法達成，程式會直接報錯，不會截斷警戒率或在 95% 之外額外疊加獎勵。

## 測試

單元測試涵蓋路線合法性、斜向／重複格、抵達底排後繼續延伸、回拖撤銷、三難度所有可達長度、起點無事件、終點有事件、警戒中止、固定 seed 重現及重複結算保護：

```powershell
node --test tests/*.test.js
```

每個難度、每個合法路線長度各跑 100,000 局的蒙地卡羅驗證：

```powershell
node scripts/monte-carlo.mjs 100000 20261113
```

第一個參數是每個組合的模擬局數，第二個參數是 seed；相同 seed 會得到相同結果。`npm test` 與 `npm run verify:rtp` 也已寫入 `package.json`，可在有 npm 的環境使用。

## 檔案結構

- `src/config.js`：難度、獎勵與下注配置
- `src/route.js`：路線編輯、合法性與可達長度枚舉
- `src/rtp.js`：RTP 公式與逐長度驗證
- `src/engine.js`：seed 亂數、事件生成、結果與單次結算
- `src/storage.js`：本機餘額、未完成局與歷史紀錄
- `src/app.js`：觸控／滑鼠互動、動畫與畫面狀態

正式上線時，投注扣款、亂數與結算應改由伺服器權威執行；此版本僅為本機 H5 Demo。
