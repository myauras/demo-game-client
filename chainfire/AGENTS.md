# chainfire（烽火連環船）

赤壁火攻主題的階梯式續押（Cash-out）博弈遊戲 HTML Demo。純靜態、零依賴、零建置——直接開 `index.html` 即可運行。

## 修改本遊戲前必讀

- 遊戲規格與運行方式見本資料夾 `README.md`。
- **可移植資產**（`js/tables.js`、`js/mock-server.js`）不得引用任何畫面相關程式；正式版將移植到 Cocos/Unity 或接真後台，這兩檔的邏輯會照搬。
- 數值鐵律：三套倍率階梯的存活率一律由 `S_n = 0.96 / M_n` 程式反推。**不可手改單一節點數值**——只改單點會破壞「任意節點收兵 EV 恆為 96%」的性質，產生可套利甜蜜點。
- 改動結果生成或數值後，開 `sim.html` 跑 ≥100 萬局驗證實測 RTP 仍與 96% 一致（判準：|偏差| ≤ max(0.1pp, 3σ)）。
- 獎池派發按風向分級：比例 = 該套最終倍率 ÷ 150，維持各風向獎池回流期望相等。此常數與規則不可任意更動。
