連鎖開箱 玩法介紹

HTML Demo｜2026-11-23 更新

按一下「開箱」，整盤箱子掉下來；同色的箱子連到 4 個以上就打開賠錢，上面的掉下來又連到就再開一次，連越多次倍率越高。一局只要按一下，幾秒鐘結束。

Demo 連結

Demo 連結：https://myauras.github.io/demo-game-client/chain-crate/

用手機直式開啟最接近實際樣子；電腦瀏覽器也能玩。不用登入，進去直接按「開箱」。

怎麼玩

  1. 選一個檔位：穩、中、拚。檔位旁的色塊數就是這一檔有幾種顏色的箱子（5、6、7 種）。顏色越多越難連到，但連到時賠得越多。
  2. 選注額：100、500 或 1,000。
  3. 按「開箱」。之後不用再做任何事，看結果就好。演出中點畫面任何地方可以加速。

規則

  • 連到就開：同色箱子上下左右相連 4 個以上算一片，整片一起打開賠錢。片越大賠越多。
  • 連鎖：打開後上面的箱子掉下來、頂端補進新箱子；又連到就再開一次，直到沒有為止。
  • 倍率階梯：每多連鎖一次，倍率升一格。穩檔最高 ×4、中檔最高 ×25、拚檔最高 ×60。
  • 金箱：角上標 ×2 的箱子。它所在的那一片賠兩倍（一片裡有兩個就是四倍）。
  • 一局最多拿回注額的 500 倍。
  • 三個檔位長期的拿回比例相同（約 96.5%），差別在「多常中」和「中的時候多大」。

一局的流程

盤面上方是倍率階梯，下方是「這局戰利品」：每開一片多一格，最右邊是這一局的累計。

其他功能

  • 最高紀錄：右下角顯示這個檔位自己打出過的最高倍數，破紀錄會慶祝一下。
  • 自動下注：「自動」鈕可以設定局數、停利、停損，自動連玩。
  • 紀錄：右上角可以看最近 50 局，點進去能看每次連鎖的倍率與賠付。

關於這個 Demo

這是用來驗證玩法的原型，下面這些不是正式的：

  • 沒有伺服器：結果在您的瀏覽器裡算出來，餘額也只存在這台裝置的瀏覽器裡，清除瀏覽資料就歸零。
  • 錢是假的：起始 10,000，玩完了可以在紀錄頁按「重置錢包」。
  • 美術是暫代：箱子、圖示、背景都是程式畫的佔位。
  • 沒有音效。
  • 「回報」鈕只會跳提示，不會真的送出。
  • 中、拚兩檔短時間的輸贏起伏很大：獎金集中在少數幾局大的，玩 50 局左右多半是小輸，偶爾一局拿回很多，這是刻意保留的設計。穩檔比較平：大約每三局有一局不虧，但幾乎不會出大獎。
