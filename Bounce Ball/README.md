# Bounce Ball 彈跳球

直式 H5 博弈小遊戲 Demo。所有金額皆為虛擬遊戲金額，不含真實金流。

## 啟動

直接用瀏覽器開啟 `index.html` 即可。若瀏覽器限制本機檔案，也可在此資料夾啟動任一靜態伺服器，例如：

```bash
npx serve .
```

## 內容

- 三種難度與不同倍率上限
- 一般球、超級球、10 球模式
- 最多 30 顆球、連續投注與自動下注
- 即時獎勵金額、球體變色、尾跡與碰撞火花
- WIN／LOSE 結算與最近五局紀錄
- WIN／LOSE 依小球實際落點判定；難度區域固定為簡單 70%、普通 50%、困難 30%
- 一般、10 球與超級球皆使用各難度原始碰撞倍率；一般球獎勵＝原下注額 × 碰撞倍率，超級球再乘額外倍率
- 固定 WIN／LOSE 區域下，以難度／模式專屬缺口大小校準目標 RTP 95%，不再縮放碰撞倍率
- 三層防卡：13.33 秒後降低內壁反彈、18.67 秒固定為 0.86、33.33 秒依最後水平位置強制結算
- 每顆球最多記錄 40 次碰撞；物理可繼續運作，但獎勵依簡單 15／普通 30／困難 25 次封頂
- 下注後等待約 0.56 秒，再於圓心用約 0.22 秒放大生成；完成後才啟動物理飛行
- WIN 特效依派彩／該球成本分級：不超過成本為碎屑、獲利但低於 2 倍為紙花、至少 2 倍為豪華紙花

機率、倍率、顏色、模式費用與目標 RTP 集中於 `game.js` 頂端的 `CONFIG` 物件。現行缺口角度依大量物理蒙地卡羅模擬校準，保留固定 70%／50%／30% 區域並直接使用原始倍率派彩。RTP 是大量遊戲後的統計期望，短期結果仍會波動；若再修改物理參數、倍率、區域或缺口，必須重新模擬校準。
