# Arena

Arena 是一款可離線執行的自動亂鬥模擬器。參賽者會由戰鬥 AI 自動移動、碰撞、累積傷害並被擊飛出場，最後留在能量環內的角色獲勝。

## 功能

- 強化追擊、衝刺、撞擊傷害與擊飛力道的高速物理戰鬥
- 五種強化模組與可選炸彈規則
- 正式開戰後立即以每秒 5.5px 縮圈，保留兩格同心圓（120px）後停止
- 自訂參賽者名稱、顏色與質量（2–16 位）
- 暫停、重置、全螢幕、音效與鍵盤快捷鍵
- 裝置本機保存的規則、名單與近 20 場戰績
- 桌面、平板與手機響應式介面

## 本機執行

需要 Node.js 22.13 以上版本。

```bash
npm install
npm run dev
```

部署版本可用 `npm run build` 產生。
