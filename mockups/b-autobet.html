二、自動下注（續押）

觀賽型遊戲的掛機需求：設好一次，接下來 N 局自動照押，人只看戲。純 UI 層實作——每局開盤時把「範本注單」自動送引擎，不碰任何凍結檔。

回答您的問題（popup 還是擺在 UI 中）：示意採兩態混合——「設定」是點 ⟳ 鈕才彈出的底部彈窗（下注區已經很密，四個欄位常駐會擠壓動物卡；手機慣例也是 bottom sheet），設完即收；「進行中」則是常駐嵌在 UI 裡的橘色浮條（進度／損益／停止鈕直接可見，不用再開窗）。若您偏好全程不彈窗，備案＝設定欄位收進注單列展開區，代價是選注空間變小——預設建議照示意做。

行為規則

  • 範本以「本局已確認的注單」為範本逐局重押（注別＋金額原樣）；賠率照每局新盤浮動。
  • 停止四種停法：跑滿局數／觸及停利／觸及停損／手動點停止。餘額不足當局自動終止＋跑馬燈提示。
  • 狀態進行中頂部常駐橘色浮條（第 n/N 局＋累計損益＋停止鈕）；每局結算照常走派彩動畫與 log 記錄，order id 照發。
  • 邊界手動加注會併入當局但不改範本；重整頁面自動狀態由 localStorage 接回（同局重整不重複下單）。
工程代價：純拋棄層（game.js＋小面板），凍結檔零接觸，估 半天。風險低，展示「掛機觀賽」的產品感很划算。
