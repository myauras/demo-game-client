# 烽火連環船｜HTML Demo

遊戲 A 的純本地 Demo。規格見上層《三款博弈遊戲企畫暨規則書_v2.md》§2、《遊戲A_Demo_開發計畫.md》。

## 運行方式

**直接雙擊 `index.html`** 即可（全部使用普通 `<script>` 串接，無 ES Modules、無建置、無依賴，`file://` 直開）。

- `index.html` — 遊戲主頁（直式手機外框，桌面瀏覽時置中）
- `sim.html` — RTP 模擬驗證頁（T03 實作）

## 檔案分界（重要）

本 HTML 版定位為**原型**，正式版可能轉 Cocos / Unity。

| 檔案 | 定位 | 轉引擎時 |
|---|---|---|
| `js/tables.js` | 可移植：三套倍率階梯，S_n = 0.96/M_n 程式反推 | 邏輯照搬 |
| `js/mock-server.js` | 可移植：後台契約（§5）本地實作、RNG、結果生成 | 邏輯照搬／換成真後台 |
| `js/game.js` | 混合：狀態流轉規則可帶走，UI/持久化為拋棄式 | 規則照搬、畫面重做 |
| `js/fx.js` | 拋棄式：江面捲動場景（倒梯形大船、鏡頭跟隨火線）——引擎版美術的「活分鏡」參考 | 用引擎特效重做 |
| `index.html`、`sim.html` | 拋棄式 | 重做 |

規則：`tables.js`、`mock-server.js` 禁止引用任何畫面相關程式。

script 載入順序固定：`tables → mock-server → fx → game`。

## 效能約束

目標裝置含較舊手機：動畫僅用 transform/opacity（CSS keyframes）、同時動畫元素約 20 個以內、無 blur/陰影動畫、JS 只在事件點執行不逐幀跑。

## 功能狀態（T01–T09 完成）

- 完整核心循環：下注 → 風向 → 逐節決策（3 秒）→ 收兵/熄滅/通關；恆定 RTP 96% 三套階梯
- 江面捲動場景：倒梯形大船、鏡頭跟隨火線、三態（未燒/燃燒/焦黑）、風向環境色調與旗幟擺動
- 結果演出：倍率金→橙→紅漸變、熄滅壓暗白煙、通關「火燒連營」全屏演出、派彩入帳 0.4s 餘額滾動
- 持久化與重連：localStorage 存錢包/設定/注單；重新整理還原未結算局至原決策節點；自動收兵離線結算
- 規則頁（RTP 揭露、倍率表由 tables.js 程式生成）、注單歷史、獎池（風向分級派發）與跑馬燈（本地模擬）
- 演出壓縮：連續遊玩 ×0.4（通關與派彩不壓縮）；設定：逾時行為、演出加速、重置錢包
