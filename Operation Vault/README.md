# 金庫行動｜Operation Vault

直式 H5 金庫破解小遊戲，無外部框架與套件，可直接以瀏覽器開啟 `index.html`。

## 操作

- 選擇四種難度之一與下注金額；按「投注」會鎖定本局設定並立即送出第一把鑰匙，後續按「破解」繼續挑戰。
- 每次成功都會把鑰匙插在旋轉圓盤外緣，跟著整個圓盤旋轉，並把累積倍率更新為難度表中的下一級。
- 完成一個圓盤後，舊圓盤縮小消失，下一個圓盤放大進場。
- 依序完成 3 個不同圓盤；鑰匙碰撞原始障礙或已插入的鑰匙時會立即失敗，獎金歸零。
- 成功一發後可隨時「提現」；獎金為本局下注額乘以目前累積倍率。
- 「自動」模式可設定自動提現鑰匙數與 10-200 局的執行局數。
- 四種難度在任一成功節點提現的理論 RTP 均為 95%。
- 點擊餘額區的 `＋` 可補充測試金額。

## 技術

- 純 HTML / CSS / JavaScript
- Web Audio API 即時合成音效
- 行動裝置直式優先，桌面置中顯示
- 遊戲畫面不顯示 Logo
