# Demon Siege — 討伐魔王軍

直式 H5 遊戲 demo。版面參考提供的範例圖，但使用原創暗黑 MOBA 美術與互動。

## 啟動

直接開啟 `index.html`，或在此資料夾啟動任一靜態 HTTP server。

## 已實作

- 戰士、弓箭手、法師三層獨立倍率圈
- 各職業 ICON 為第 0 階起點，初始狀態不顯示倍率進度
- 最終倍率後不設紫色節點，抵達最終倍率時整圈進度填滿
- 戰士／弓箭手／法師／沉默術／魔王五種回合事件
- 戰士輪轉圖示使用 96×96 輕量 WebP 資產
- 戰士、弓箭手、法師命中時同步播放紅／綠／藍無圓框職業 ICON 特效並延伸倍率條
- 沉默術在 1 秒內將整個圓盤轉為灰階，並在三個職業起點同步顯示「...」
- 魔王蓄力、爪擊斬痕、衝擊波與輪盤震動特效
- 下注額減半、加倍與快速設定
- 任一倍率圈存在進度時鎖定投注金額，倍率歸零後恢復調整
- 部分結算、全部結算與按鈕狀態
- 最終倍率自動結算
- 部分結算與最終倍率領獎飛行時，倍率圈進度同步倒退
- 戰士 BONUS 100X／200X／300X／400X 演出
- 理論 RTP 0.95（以命中職業後立即全部結算的最高基準策略校準）
- 右上角單次必勝測試按鈕，啟用後下一局保證命中職業並自動關閉
- 手機直式與桌面置中預覽

遊戲邏輯先決定結果，再播放結果動畫；動畫本身不參與結果計算。
