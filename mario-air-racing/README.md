# mario-air-racing

正式遊戲由 [myauras 的 GitHub Pages](https://myauras.github.io/demo-game-client/mario-air-racing/) 提供。`master` 保存本專案原始碼，`gh-pages` 分支的 `mario-air-racing/` 放置 `dist/` 內的檔案。

用支援 WebGL 的瀏覽器開啟 [dist/index.html](dist/index.html) 即可遊玩。五位機師依序是瑪利歐、庫巴、碧姬公主、奇諾比奧和耀西，各自駕駛紅帽雙翼機、帶雙機械爪的黑鐵爪艦、皇冠噴射機、蘑菇水上機與蛋殼雙引擎機。

若要使用本機預覽網址，在本目錄執行下列指令，再開啟 [本機遊戲](http://127.0.0.1:4186/)。

```powershell
python -m http.server 4186 --bind 127.0.0.1 --directory dist
```

遊戲點數與當局進度儲存在瀏覽器。固定使用同一個瀏覽器和網址即可沿用進度。

## 倍率與結算

倒數 7 秒後起飛。飛行、障礙物和場景隨時間持續加速。後段的近雲比遠雲更快掠過，翼尖凝結尾流隨航速拉長，地景在高速時帶輕微的方向性模糊。進入延長賽時鏡頭會短暫拉廣一次。一般賽段約 16.1 秒，任一架在飛行中達 1.50× 即延長至約 22.8 秒，上述時間另加衝線演出。每條賽道的風勢決定危險物的密度和強度。2,048 條賽道中有 1,216 條會全數墜機，最後一架墜落即收尾。飛機從 0.10× 起步，每 20 個模擬步累積 0.01×，金幣另外累加，基礎倍率上限為 100×。吃到金幣時，接觸點亮起白金色星芒、散開金色光環與火花，只有實際拾取金幣的飛機會點燃尾部噴射引擎、短暫向前衝刺。空域許可時，機師偶爾會做一次側滾。

海洋沿途有長著棕櫚與闊葉樹的岩島。瀑布從草坡越過崖緣落海，水花與潮面一起起伏，彩虹從雲後橫跨海面。海鷗在海洋出現。進入雪場後會遇上冰雹，暴風雪中的機頭會隨陣風快速、不規則地俯仰與偏轉。大型海鳥、冰雹或高速火隕石直接擊中機體會造成墜機。亂流中，兩架景深相近的飛機高速靠近並撞上時，也會一起墜落。隕石擊中機體時，接觸點會沿來向迸出橙金色撞擊閃光與碎屑；重擊會接上機身爆炸。自己下注的飛機碰撞時，賽道短暫閃光；被撞時鏡頭會後坐、微幅傾斜並回穩。墜機時震動加重，賽道稍微轉灰，下一局恢復原色。

金色皇冠標記當下飛在最前面的飛機，實際超越前機時，機師旁會冒出愛心對話框。賽段結束時，存活飛機按前後位置進入衝線直道，每架通過氣球吊起的方格彩帶時噴出彩紙，並持續加速飛出畫面。第一架直接衝過終點時，機頭上方跳出「冠軍／加倍獎勵 ×2」，倍率從基礎值跳到兩倍。鏡頭自過線瞬間起跟拍冠軍 0.5 秒，再切回終點線的固定廣角。後續飛機快速過線，按自己的基礎倍率結算。全數墜機時沒有冠軍，每架均按墜機倍率結算。

後機會對準前機的高度與景深，從機尾追撞。前機會落後一段距離，將 0.10× 轉給後機。前機有足夠的額外倍率且後機有收取空間時才會觸發。接觸點會迸出閃光，後機的倍率以金字上跳，前機的倍率以紅字下沉。追撞、道具和派彩由已抽出的賽道按固定模擬步重播，加速曲線決定每秒推進的步數，鏡頭、畫面更新率與亂流線只影響顯示。

每台飛機有 2,048 條等機率賽道，每條賽道有五種等機率機位輪替。計入冠軍雙倍後，每台的 10,240 種結果合計派彩 9,728 倍單注，理論 RTP 各為 95%。更新前已開的局沿用該局儲存的規則版本。
