空投爭奪（Hot Drop）玩法介紹

HTML Demo・手機直式・2026-11-17

空投爭奪是一款吃雞空投主題的選點博弈。你和三個對手同時從四個落點裡選一個跳傘：只有你一個人落在那裡，才拿得到那裡的物資；跟別人撞在同一點，就什麼都沒有。賠率越高的落點，對手也越愛去。

https://myauras.github.io/demo-game-client/hotdrop/

用手機直式開啟最接近實際畫面；電腦瀏覽器也能玩。錢包是本機的試玩幣，玩完可以在紀錄頁重置。

規則

  • 四個落點：綠、藍、紫、金，賠率由低到高。每一局的賠率都會重新開出，落點的圓圈裡直接寫著這一局的賠率與勝率。
  • 獨佔才有獎：你選的落點只有你一個人，就拿到「下注 × 落點賠率」。只要有任何一個對手跟你同點，這一局歸零。
  • 開箱再加倍：獨佔之後會開一個箱子，把獎金再乘一次。箱子有四級：軍用箱 ×1、精良箱 ×1.5、稀有箱 ×2、傳說箱 ×5。最差也是 ×1，不會倒扣。
  • 高賠高風險：金點賠率最高，但對手也最常選它，勝率大約只有兩成多；綠點賠率低，但勝率有七成左右，而且贏了一定不虧。
  • 每局只下一注：選一個落點、一個金額（10／50／100／500）。

一局怎麼玩

① 選落點。 進場就是俯視地圖。上方是三個對手的喊話（只是氣氛，不一定是真的；提到的落點會用該落點的顏色標出來）。選好單注金額，點一個落點就開局。

② 封盤倒數。 點下落點後有 3 秒倒數，這段時間可以改點，也可以按「立即跳傘」直接開始。倒數結束就鎖定。

③ 跳傘與揭曉。 四個人各自落向自己選的點，每個落點上會出現落在這裡的人的頭像：只有一個人的亮起來並打勾，兩人以上的變紅。

④ 結果。 地圖中央彈出結果：

  • 獨佔：顯示開到的箱子倍率、最後倍率、贏得多少；外框是你選的落點顏色。
  • 大獎：最後倍率達 5 倍以上時彈窗變金色並噴金幣。
  • 撞車：顯示跟誰撞在一起，結果 0x。

點一下收起彈窗，新一局的賠率就換上來，再點落點開下一局。一局大約 6 秒，按立即跳傘約 3 秒。

其他功能

  • 近況：畫面最下面一排圓點，每顆代表一局「獨佔成功的落點裡賠率最高的那個顏色」；灰色是那一局四個人全部撞車。最新的在最右邊。
  • 自動下注：單注列右邊的「自動」鈕。可以設定固定跳哪個落點（或四色輪流）、單注、局數、停利與停損。進行中上方會顯示第幾局與累計輸贏，隨時可停止。
  • 勝負紀錄：右上角的紀錄鈕。列出最近 50 局的輸贏，點任一筆可以看那一局的小地圖：誰跳哪裡、誰獨佔、誰撞車。

關於這個 Demo

  • 這是驗證玩法用的原型，重點是玩起來的感覺。
  • 三個對手是本機的機器人，不是真人；它們的喊話是隨機的氣氛文字，跟實際落點無關。
  • 錢包與紀錄只存在你自己的瀏覽器裡。
  • 畫面上的美術全部是佔位圖，特效（例如噴金幣）之後會重做。
  • 整體返還率設計為 96%，選哪個落點長期期望都一樣，差別在輸贏的起伏大小。
